# Roadmap

阶段之间是**硬门槛**，不到出口标准不进入下一阶段。理由：这个项目最大的风险不是做不完，是「什么都做了一点，什么都不能演示」。

## P0 · 样板房（当前，约 2 周）

目标：**能给人看的一段 60 秒演示**，以及一套后续不会返工的 IR。

已交付（骨架）：

- `cs-core`：IR 六件套 + 分流四态 + `ConversationService` + 五个 port + `TraceRecorder` + 降级话术
- `cs-bot`：`/api/chat` + `BlockView` 线格式 + 经纪域 Agent（确定性分支：订单卡片/退保条款/材料清单/交接包）
- 库表 `V1`（8 表）+ `V2` 虚构种子（10 条规则 + 2 条 disabled 扩展规则）
- 16 个测试；`mvn test` 绿；jar 可启动、curl 可通

剩余：

1. `LlmPort` 的 OpenAI 兼容实现（DeepSeek / 本地 vLLM 同形状）
2. 退保条款问答走「检索 + 模型」，保留确定性兜底
3. Vue3 对话窗（卡片/选项/「查看 trace」抽屉）
4. handoff 落表 + 极简待处理列表
5. `/api/chat` 加 SSE 版本（`TurnResult` 切块，协议不变）

**出口**：录屏 60 秒，五个画面齐全（对话、卡片、引用、交接包、trace 抽屉）。

## P1 · 地基（3–4 周）

目标：从「演示」变成「系统」。

- 接 MariaDB（Flyway 已就位）、Redis（会话摘要/规则缓存）
- 规则从代码搬到 `route_rule` 表 + 60s 缓存（刷新失败保留旧值）
- 记忆：按 `seq` 读最近 10 轮（**不按时间戳排序**——多源合并时时间戳会打架）
- 三级路由真正跑起来：entry → `ins.triage` → broker（延保/商家险保留 `enabled=0`）
- 工具四件：`order.query` / `policy.query` / `refund.quote` / `surrender.quote`，带幂等键、超时、熔断
- 检索：本地向量 + 关键词双路，三态阈值（0.8/0.3）可配置
- 合规话术规则 + 最小合规检查
- Langfuse 旁路导出（OTLP，异步，允许丢）
- Nacos 只做配置中心（参数/开关），不做路由事实源

**出口**：一次请求可追到 `turn` → `span` 树 → 规则 id → 话术版本；`route_state` 分布能出图。

## P2 · 卫星系统（每个 2–3 周，顺序固定）

1. **badcase 收集箱**（最先，2–3 天）— 人工标记坏例，导出 JSONL
2. **轨迹回放** — traceId → 时间轴（问了什么 / 怎么判断 / 调了什么 / 慢在哪）
3. **评测台** — 黄金集 + L1/L2/L3 三层断言 + run diff
4. **运营配置台** — 规则/话术/prompt 版本管理（草稿→对比→发布，发布内容落 git）
5. **成本看板** — token/耗时/模型分布，按域与规则命中分组
6. **话术质检** — 抽样 + LLM 打分周报

## 长期纪律

- **Flyway 只增不改**：改历史迁移 = 别人的库和你不一样
- **ADR 只增不改**：要推翻就新写一条并标注 supersedes
- **契约测试先于新功能**：新增 SubAgent 先写契约测试（必产 TOOL span、必有降级话术、不确定必给候选）
- **每次合并前 `mvn test` 绿**；不许「先合了再修」

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 弱网上开发体验差（每次请求 60ms） | 单请求往返 ≤3；本地缓存规则；trace 异步 |
| 想做的太多，样板房拖成半成品 | P0 五画面硬切；宁可砍 UI，不砍 IR |
| 接模型后幻觉失控 | 检索三态 + 编号候选 + 合规拦截；不确定就反问 |
| 只有自己维护，三个月后看不懂 | 规则进仓库、ADR 记理由、`.agents/` 存上下文、注释写代价 |
